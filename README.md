# weavegraph

Weave digests and graph fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/weavegraph/

## Install / run

```bash
git clone https://github.com/theworker02/weavegraph.git
cd weavegraph
node src/cli.js
node --test
```
